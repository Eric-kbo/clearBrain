# clearBrain · 个人精力管理评分表

> 判断一个行为是在消耗你，还是在恢复你。

**在线访问：** https://eric-kbo.github.io/clearBrain/

---

## 项目简介

这是一个纯静态网页工具，帮助你评估日常行为对注意力与行动力的影响。无需安装、无需登录，打开即用。

**功能特点：**
- 🧠 对任意行为进行多维度评分
- 📊 实时计算综合得分并给出建议
- 🌗 支持亮色 / 暗色主题
- 📱 移动端友好，响应式布局
- 🔒 所有数据仅保存在本地浏览器，不上传任何信息

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何构建工具或服务器。

```bash
open index.html   # macOS
start index.html  # Windows
```

## 部署

本项目通过 GitHub Actions 自动部署到 GitHub Pages。每次向 `main` 分支推送时自动触发部署。
